Choose a name, then create a room or join a friend's room code.

How to play
  1. At least 2 players join from separate devices using the same room code.
  2. The host presses Start Game. Each round has a hidden word and a clue.
  3. Choose letters or type a full-word guess before the 60-second timer ends.
  4. Earn 1 point for each matching letter revealed, 3 bonus points for completing the word, or 5 bonus points for a correct full-word guess.
  5. There are 5 rounds. The highest score wins!
